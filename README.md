# Magpie Techworks website

Source for https://magpietechworks.com, hosted on GitHub Pages.

## Files

- `index.html` – the whole one-page site (styles and logo are inline)
- `favicon.svg` – browser tab icon
- `CNAME` – tells GitHub Pages to serve the site on magpietechworks.com

## Updating the site

Edit `index.html` and commit to the `main` branch. GitHub Pages republishes automatically within a minute or two.
